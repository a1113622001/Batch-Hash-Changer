# 批量文件哈希值修改工具 (Batch File Hash Modifier) v11.0

基于 PowerShell 动态编译 C# + Win32 API (P/Invoke) 实现的批量文件哈希修改工具。
通过在文件末尾追加 1~4 个随机字节改变文件的 MD5/SHA1 等指纹，用于规避云端存储的"秒传/去重"机制，同时借电梯算法(按物理簇号排序)与时间戳保留来降低 HDD 开销并保持文件元数据不变。

## 文件清单
- 批量文件哈希值修改工具 v11.0.ps1 - 主程序（真正的脚本本体）
- 批量文件哈希值修改工具 v11.0.bat - 一键启动器（用资源管理器双击即可运行，它会调用同目录的 .ps1）

## 使用方式
1. 双击 批量文件哈希值修改工具 v11.0.bat；或在命令行运行：
   powershell -NoProfile -ExecutionPolicy Bypass -File "批量文件哈希值修改工具 v11.0.ps1" <目录路径>
2. 按提示输入 / 传入要处理的文件夹路径。
3. 等待处理完成，查看"成功 / 跳过"统计。

> 提示：读取磁盘簇号(LCN)需要相应权限，建议以管理员身份运行。
> 警告：修改哈希会破坏文件的完整性校验（CRC/MD5 等），请谨慎使用。

## v11.0 相对 v10.6 的优化
1. 真正保留时间戳：写入前读取原始创建/访问/修改时间，写入后原样还原（v10.6 误将时间戳设为 0xFFFFFFFF 的"垃圾未来日期"）。
2. LCN 读取改为可变大缓冲：分片文件也能正确排序，电梯算法对 HDD 的优化不再因 32 字节小缓冲失效。
3. 失败 / 跳过统计：写入失败与跳过数量单独统计并汇总，不再静默吞错。
4. 进度与速率：实时显示处理进度、速率与预计剩余时间。
5. 共享模式：以读/写/删除共享打开文件，降低"文件被占用"导致的失败率。
6. 真正可双击的 .bat 启动器（v10.6 的 .bat 实为 PowerShell 脚本，双击不会执行）。
7. 健壮性：无法读取簇号时文件仍会处理（排到最后），不会漏处理；增加管理员权限检测。

## 技术原理
- 哈希唯一化：文件末尾追加 1~4 个随机字节，改变文件指纹。
- 物理簇排序：通过 DeviceIoControl + FSCTL_GET_RETRIEVAL_POINTERS 获取文件首簇号(LCN)，按物理位置升序处理，降低机械硬盘磁头寻道延迟。
- 元数据保护：GetFileTime / SetFileTime 在修改前后锁定时间戳。
- 底层调用：C# 动态编译，P/Invoke 直达 kernel32.dll，流式枚举 + 分批处理控制内存占用。

## 适用平台
Windows（PowerShell 5.1+）。

## 安全提示
该工具会实际修改文件内容。运行前请备份数据，并确认目标目录内的文件允许被修改。
